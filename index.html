Figma PAT 발급 순서

  1. Figma 파일 브라우저 왼쪽 위 계정 메뉴에서 Settings를 엽니다.
  2. Security 탭의 Personal access tokens 영역에서 Generate new token을 누릅니다.
  3. 토큰 이름, 만료일, 필요한 scope를 선택하고 Generate token을 누릅니다.
